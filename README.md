# One Dream × myPAL

Six-page HTML proposal for the One Dream centre operations build and reuse of the existing myPAL Marketing suite.

Open `index.html` directly, or run `python3 -m http.server 8000` and visit http://localhost:8000. No build step or dependencies are required.

The marketing page uses cropped product references and links into the existing myPAL workspace. This is a proposal site; it does not provision accounts, connect APIs, send messages or process payments. The commercials page identifies the proposal PDF as its source; executed agreement terms are handled separately.
